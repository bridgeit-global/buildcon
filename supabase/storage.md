## Buckets

Create these **private** buckets in Supabase Storage:

- `kyc`
- `documents`
- `signatures`

## Path conventions

Use predictable paths so policies can restrict access:

- `kyc/customer/<customer_id>/<doc_type>/<uuid>.<ext>`
- `documents/project/<project_id>/<category>/<uuid>.<ext>`
- `signatures/project/<project_id>/<uuid>.<ext>`

## Policy strategy (MVP)

For MVP we’ll keep file access behind signed URLs generated by the app server, so we don’t need broad public Storage policies.

When ready to enforce Storage RLS strictly:

- Allow reads if the requester is an authenticated staff user.
- Tighten further by linking files to rows (e.g. `customer_kyc_documents.storage_path`) and verifying access via joins.
